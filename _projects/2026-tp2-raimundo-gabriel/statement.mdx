<Language code="es">

Random Loop se trata de una búsqueda inmersiva, el video en loop de un patrón abstracto, en el cual varía una máscara geométrica de círculos concéntricos. Se puede activar y desactivar la música de fondo.

**Desarrollo técnico, estético y conceptual**

Para la obra se utilizó un video de patrón abstracto vinculado al humo, líquidos, con música sci-fi de fondo buscando una experiencia inmersiva, invitando al espectador a contemplar el loop, aunque sea por unos segundos sin tener la necesidad de hacer algo.

**Bibliografía**

Usando de referencia el texto de Inke Arns *El codigo como habla performativo* podria definir esta obra, produccion como Arte Generativo a partir de las definiciones que brinda el texto. El software es utilizado comon herramienta pragmatica neutral, no define ni varia el resultado final ni incomoda al espectador, devuelve una obra, un producto terminado. No se esconden textos politicos, intervensiones en dispositivos ni manipulacion de contenido, cosa que si se podria realizar con Arte Software.
Luego podria relacionar el Arte Generativo con el uno de los tres actos linguisticos, el acto inlocutivo, en el que decir es tambien hacer algo. En este caso el lenguaje de programacion dice, tiene escrito algo que se manifiesta en una accion, una visualizacion, una interaccion.

<Language code="en">

Random Loop is an immersive search: a looping video of an abstract pattern in which a geometric mask of concentric circles varies. The background music can be turned on and off.

**Technical, aesthetic, and conceptual development**

For the work, an abstract pattern video linked to smoke and liquids was used, with sci-fi background music seeking an immersive experience, inviting the viewer to contemplate the loop, even if just for a few seconds without feeling the need to do something.

**Bibliography**

Using Inke Arns's text *Code as Performative Speech Act* as a reference, I could define this work/production as Generative Art based on the definitions provided in the text. The software is used as a neutral pragmatic tool; it neither defines nor varies the final result nor makes the viewer uncomfortable—it returns a finished work, a completed product. No political texts, device interventions, or content manipulations are hidden, which could be done with Software Art.
Then I could relate Generative Art to one of the three linguistic acts, the illocutionary act, in which saying is also doing something. In this case, the programming language says—has something written—that manifests in an action, a visualization, an interaction.
